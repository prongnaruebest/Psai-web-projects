# NEXUS PROMPT HUB (Prompt Hub MAX)
### Futuristic AI & Web Engineering Prompt Catalog & Generation Platform

- **index.html**: Futuristic space-themed interactive web application with Particle Background, Mouse Light Trails, Click Ripples, and Gemini API integration.
- **web_prompt_hub.html**: Original Prompt Hub interface.
- **Prompts Datasets**: `ai_money_prompts_100.json`, `ai_money_prompts_200.json`, `web_prompts_100.json`.
- **Scripts**: Python utilities for scraping, merging, enriching, and updating effects.
- **Run**: Double-click `start_web.bat` or run `python server.py 8080`.
