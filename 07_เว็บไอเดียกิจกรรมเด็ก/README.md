# 🎨 PlayPal: รวม 32+ ไอเดียกิจกรรมเล่นกับลูก สนุก ปลอดภัย ในบ้านและทุกที่

> **โปรเจกต์ลำดับที่ 03** ในศูนย์รวมเว็บแอปพลิเคชัน (Psai Web Projects)  
> คลังรวม 32+ ไอเดียกิจกรรมการเล่นสร้างสรรค์กับลูก เสริมทักษะประสาทสัมผัสและกล้ามเนื้อ ใช้อุปกรณ์ง่ายๆ ในบ้าน รองรับ PWA

---

## 🌟 ฟีเจอร์หลัก (Key Features)

1. **คลัง 32+ กิจกรรมสร้างสรรค์:**
   - คัดสรรกิจกรรมที่ส่งเสริมพัฒนาการด้านประสาทสัมผัส (Sensory Play), กล้ามเนื้อมัดเล็ก-มัดใหญ่, ความคิดสร้างสรรค์ และสมาธิ
   - กรองตามช่วงอายุของลูก (วัยเตาะแตะ, วัยอนุบาล, วัยประถมต้น)
   - กรองตามประเภท: งานศิลปะ, การทดลองวิทยาศาสตร์ง่ายๆ, ดนตรีและการเคลื่อนไหว, กิจกรรมในครัว
2. **ใช้วัสดุอุปกรณ์ที่หาได้ง่ายในบ้าน:**
   - กล่องกระดาษ, ฝาขวด, ข้าวสารย้อมสี, แป้งโดว์ทำเอง, น้ำเปล่า, หลอดดูด
   - มีรายการอุปกรณ์และขั้นตอนการเล่นทีละขั้นตอนพร้อมข้อควรระวังเรื่องความปลอดภัย
3. **ระบบค้นหาและบันทึกกิจกรรมโปรด:**
   - ค้นหากิจกรรมได้อย่างรวดเร็วตามคำสำคัญ
   - กดรูปหัวใจเพื่อบันทึกเป็นกิจกรรมโปรดของครอบครัว
4. **รองรับ PWA & Offline:**
   - ติดตั้งลงบนหน้าจอโฮมของสมาร์ตโฟนหรือแท็บเล็ตได้เสมือนแอปจริง
   - ออนไลน์ Live บน [https://prongnaruebest.github.io/playpal-web/](https://prongnaruebest.github.io/playpal-web/)
