# 🧬 Muscle Map: แผนที่กล้ามเนื้อและกายวิภาคศาสตร์ 2D/3D

> **ระบบแผนที่กล้ามเนื้อและการฝึกเฉพาะส่วน** (ส่วนหนึ่งของ FastFit Studio Suite)  
> แสดงกายวิภาคศาสตร์กล้ามเนื้อร่างกายมนุษย์แบบ Interactive คลิกเลือกส่วนกล้ามเนื้อเพื่อดูท่าออกกำลังกายที่ตรงจุด

---

## 🌟 ฟีเจอร์หลัก (Key Features)

1. **แผนที่กายวิภาคศาสตร์ Interactive SVG (ชาย/หญิง):**
   - แสดงกลุ่มกล้ามเนื้อทั้งด้านหน้าและด้านหลัง (Anterior & Posterior Views)
   - สลับโมเดลสรีระเพศชาย (Male) และเพศหญิง (Female) ได้อย่างอิสระ
   - ไฮไลต์กล้ามเนื้อเมื่อนำเมาส์ไปชี้ พร้อมบอกชื่อทางการแพทย์และชื่อสามัญ
2. **คลังท่าบริหารกล้ามเนื้อ (Exercise Database):**
   - อก (Chest), หลัง (Back), ไหล่ (Shoulders), แขน (Arms / Biceps / Triceps), แกนกลางลำตัว (Core / Abs), และขา (Quads / Hamstrings / Calves)
   - แนะนำท่าฝึกทั้งแบบ Bodyweight (ใช้น้ำหนักตัว), Dumbbell, Barbell และ Cable Machine
3. **ระบบกรองและคำแนะนำ:**
   - ระดับความยากง่าย (Beginner / Intermediate / Advanced)
   - คำแนะนำโฟกัสการเคลื่อนไหวเพื่อหลีกเลี่ยงการบาดเจ็บ

---
