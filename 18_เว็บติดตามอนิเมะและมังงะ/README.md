# TrackToon & Donghua 🎬📖
> **ระบบบันทึกความคืบหน้า อนิเมะจีน & มันฮวา/มังงะ ประจำวัน**  
> *โปรเจกต์เว็บแอปพลิเคชันลำดับที่ 18 ใน Psai Web Projects*

---

## 🌟 ฟีเจอร์เด่นเพื่อการใช้งานประจำวัน (Daily Tracker)

1. **ปุ่มกดเร็ว +1 ตอนทันใจ (One-Tap Bump)**:
   - ไม่ต้องเสียเวลาพิมพ์แก้เลขตอน เพียงกดปุ่ม **[ +1 ตอน ]** หรือ **[ +5 ]** ตัวเลขตอนจะอัปเดตและบันทึกเวลาล่าสุดทันที
   - มีปุ่ม **[ -1 ]** กรณีเผลอกดเกิน
   - หรือคลิกที่ตัวเลขตอนโดยตรงเพื่อพิมพ์เลขตอนใหม่ได้ทันที

2. **มีข้อมูลตั้งต้นครบ 25 เรื่อง (Preloaded 25 Titles)**:
   - **อนิเมะจีน (Donghua) 6 เรื่อง**: หวี่เฮ่า/ภูตถังซาน 2, หวังหลิน/ฝืนลิขิตฟ้าข้าขอเป็นเซียน, หลัวเฟิง/มหาศึกล้างพิภพ, เซียวเหยียน/สัประยุทธ์ทะลุฟ้า, หานลี่/คัมภีร์วิถีเซียน, ฉินมู่/ตำนานเทพกู้จักรวาล
   - **อ่านตูน (Manhwa / Manga / Webtoon) 19 เรื่อง**: Solo Max-Level Newbie, Pick Me Up Infinite Gacha, Nano Machine, Revenge of the Sword Hound, Solo Leveling Ragnarok, Killer Peter, ฯลฯ ครบทุกเรื่องตามที่คุณใช้งาน

3. **ค้นหาตอนถัดไปในคลิกเดียว (1-Click Next Episode Search)**:
   - แต่ละเรื่องจะมีปุ่ม **"หาตอน [X]"** กดแล้วจะเปิด Google เพื่อค้นหาตอนถัดไปของเรื่องนั้นทันที ประหยัดเวลาพิมพ์ค้นหาในแต่ละวัน

4. **ปักหมุดเรื่องโปรด (Favorites ⭐)**:
   - กดรูปดาวเพื่อปักหมุดเรื่องที่กำลังตามติดให้ขึ้นมาอยู่อันดับบนสุด (เช่น *หวังหลิน)

5. **คัดลอกสรุปข้อความ (Copy Text Summary)**:
   - กดปุ่ม **"คัดลอกสรุป"** ระบบจะแปลงสถานะล่าสุดเป็นข้อความตามรูปแบบเดิมที่คุณใช้จดเป๊ะๆ พร้อมส่งต่อเข้า LINE, Memo หรือ Notepad ได้ทันที

6. **นำเข้าข้อความดิบ (Smart Raw Text Import)**:
   - หากมีรายการใหม่จากที่อื่น สามารถก๊อปปี้ข้อความมาวาง ระบบจะแยกหมวดหมู่ ชื่อเรื่อง ตัวละคร และเลขตอน `ep / ตอนที่` ให้อัตโนมัติ

7. **ระบบสำรองข้อมูล (JSON Backup & Restore)**:
   - ดาวน์โหลดไฟล์ `.json` เก็บไว้ในเครื่อง หรือนำเข้าไฟล์กลับมาได้ ไม่ต้องกลัวข้อมูลหาย

8. **โหมดมืด OLED / สว่างแบบคลิกเดียว (Dark / Light Mode Toggle)**:
   - ปุ่มสลับธีม 🌙 โหมดมืด (Deep Slate OLED) และ ☀️ โหมดสว่าง สะอาดตา สบายตาขณะอ่านตอนกลางคืน บันทึกการเลือกอัตโนมัติ

9. **ตารางฉายประจำสัปดาห์ & ป้ายเตือนตอนใหม่ออกวันนี้ (Weekly Broadcast Schedule)**:
   - กรองดูตามวันฉาย จันทร์ - อาทิตย์ หรือกดดูเฉพาะ **[ 🔥 ฉายวันนี้ ]**
   - มีป้ายแจ้งเตือน **"🔥 ตอนใหม่ออกวันนี้!"** กระพริบสะดุดตาทันทีเมื่อถึงวันปล่อยตอนใหม่
   - กำหนดและแก้ไขวันฉายได้ในหน้าต่างแก้ไขเรื่อง (Edit Modal)

2. หรือเปิดไฟล์ `index.html` ในเบราว์เซอร์ Google Chrome / Edge / Safari
3. หรือเปิดผ่านหน้าศูนย์รวม `00_ศูนย์รวมเว็บแอปพลิเคชัน.html`
