# 🔭 เว็บพอร์ตโฟลิโอวิศวกร (Psai Naruebest • 2 โหมดในเว็บเดียว)

> **โปรเจกต์ลำดับที่ 09** ในศูนย์รวมเว็บแอปพลิเคชัน (Psai Web Projects)  
> เว็บไซต์แสดงประวัติและผลงานวิศวกรรมฉบับสมบูรณ์ ผสาน 2 แนวทาง (สตอรี่สากล + เรซูเม่ทางการ) เข้าด้วยกันอย่างลงตัว สลับโหมดได้ทันใจผ่านแท็บด้านบน

---

## 🌟 จุดเด่นและ 2 โหมดการใช้งาน (Dual Modes)

เว็บไซต์นี้รวมผลงาน 2 มิติเข้าด้วยกันในเว็บเดียว ไม่ต้องแยก 2 เว็บไซต์ให้สับสน:

```
┌────────────────────────────────────────────────────────────────────────┐
│  [PN] Psai Naruebest   [ 🔭 สตอรี่สากล (Overview) | 📄 เรซูเม่ทางการ ] │
└────────────────────────────────────────────────────────────────────────┘
```

### 1. 🔭 โหมดสตอรี่สากล (Overview - Psai Play)
- **สไตล์:** ดำมินิมอล (Dark Minimalist Theme) สไตล์เว็บพอร์ตโฟลิโอสากล
- **เนื้อหาหลัก:**
  - นำเสนอเรื่องราวการทำงานจริงในระบบหอดูดาวระดับโลก **"Engineering systems from circuit boards to the stars"**
  - ประสบการณ์บริหารและดูแลระบบกล้องโทรทรรศน์อัตโนมัติ สดร. (NARIT Thai Robotic Telescope)
  - งานติดตั้งและปฏิบัติการภาคสนาม ณ หอดูดาวระดับโลก:
    - 🇨🇱 **CTIO (Cerro Tololo Inter-American Observatory)** ประเทศชิลี
    - 🇺🇸 **SRO (Sierra Remote Observatory)** สหรัฐอเมริกา
    - 🇨🇳 **Gao Mei Gu Observatory** ประเทศจีน
  - การออกแบบและพัฒนาวงล้อแก้วกรองแสงความแม่นยำสูง **TRT Filter Wheel V2** (รองรับ 23 ฟิลเตอร์)
  - แกลเลอรีภาพถ่ายการทำงานภาคสนามและมุมมองชีวิต
- **ฟังก์ชันเสริม:**
  - สลับภาษาได้ทันที **TH / EN** (รองรับผู้เข้าชมชาวต่างชาติ)
  - เมนูมือถือ Slide-down
  - Scroll Reveal Animations แสดงคอนเทนต์แบบนุ่มนวล
  - แบนเนอร์ท้ายหน้ากดข้ามไปยังเรซูเม่ฉบับทางการได้ทันที

### 2. 📄 โหมดเรซูเม่ทางการ (Full Technical Resume)
- **สไตล์:** ขาวสว่าง สะอาด เรียบร้อย (Clean Professional Theme) เหมาะสำหรับการสมัครงานและเสนอผลงานต่อคณะกรรมการ
- **เนื้อหาหลัก:**
  - สรุปความเชี่ยวชาญด้านวิศวกรรมอิเล็กทรอนิกส์และระบบฮาร์ดแวร์เชิงลึก
  - **ออกแบบวงจรพิมพ์ (Multilayer PCB Design):** ความละเอียด 2-8 ชั้น ตามมาตรฐานสากล IPC
  - **ตู้ควบคุมระบบไฟฟ้า (Electrical Integrated Control Cabinet):** PLC, Relay Logic, Safety Circuit
  - **วิศวกรรมเครื่องกล 3D (SolidWorks CAD):** งานกลึง มิลลิ่ง ขึ้นรูปชิ้นงานโลหะความแม่นยำสูง
  - **ผลงานและโครงการเด่น:** Smart PLC (STM32 + OLED + Ethernet), RFI Mount, Housing Weather Station
  - **ประวัติการศึกษา & ใบทรานสคริปต์ (Transcript):** มหาวิทยาลัยเทคโนโลยีราชมงคลล้านนา ภาคพายัพ เชียงใหม่
  - **ใบรับรองความสามารถ (Certificates):** 5 ใบรับรองมาตรฐาน
- **ฟังก์ชันเสริม:**
  - ปุ่มดาวน์โหลด **Resume PDF (A4)** บันทึกลงเครื่องได้ในคลิกเดียว
  - ตารางเปรียบเทียบสถิติและผลงานเชิงปริมาณ
  - แถบเมนูลอยแบบย่อส่วน (Sub-navigation)

## ⚡ การสลับโหมดและการนำทาง (Navigation)

1. **แถบ Master Mode Switcher (ด้านบนสุด):** ลอยติดขอบบนเสมอ คลิกเลือก `สตอรี่สากล` หรือ `เรซูเม่ทางการ` ได้ทันที
2. **URL Hash Routing:**
   - `#overview` → เปิดแสดงโหมดสตอรี่สากล
   - `#resume` → เปิดแสดงโหมดเรซูเม่ทางการ
   - รองรับการแชร์ลิงก์เจาะจงโหมด หรือคลิกจาก Hub หน้าหลัก
3. **จดจำสถานะ (LocalStorage):** ระบบจะจดจำโหมดที่คุณเปิดล่าสุดไว้โดยอัตโนมัติ
