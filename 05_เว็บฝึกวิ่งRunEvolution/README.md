# 🏃 RunEvolution: ก้าวสู่นักวิ่งพันธุ์แกร่ง & ปลุกพลังกล้ามเนื้อ

> **เว็บฝึกวิ่งและคำนวณการวิ่งครบวงจร** (ส่วนหนึ่งของ FastFit Studio Suite)  
> ระบบวางแผนตารางซ้อมวิ่งมาราธอน คำนวณความเร็ว Pace และเครื่องเคาะจังหวะก้าวเท้าเพื่อพัฒนาศักยภาพนักวิ่ง

---

## 🌟 ฟีเจอร์หลัก (Key Features)

1. **ตารางฝึกซ้อมวิ่งมาตรฐาน (Training Schedules):**
   - รองรับทุกระยะ: 5K, 10K, Half Marathon (21.1 km) และ Full Marathon (42.195 km)
   - แบ่งเฟสการฝึก: Base Building, Speed Work, Long Run และ Tapering
2. **เครื่องคำนวณความเร็ว Pace (Pace & Time Calculator):**
   - แปลงความเร็ว Pace (นาที/กิโลเมตร) เป็น km/h
   - ประเมินเวลาจบการแข่งขัน (Finish Time Prediction)
   - ตารางคำนวณ Split Times รายกิโลเมตร
3. **เครื่องเคาะจังหวะรอบขา (Cadence Metronome):**
   - สังเคราะห์เสียงเคาะจังหวะผ่าน Web Audio API
   - ปรับแต่ง SPM (Steps Per Minute) เช่น 170-185 SPM เพื่อป้องกันการบาดเจ็บและวิ่งได้ประหยัดพลังงาน
4. **ความรู้เรื่องกล้ามเนื้อและโภชนาการนักวิ่ง:**
   - ท่ายืดเหยียดก่อน-หลังวิ่ง (Dynamic & Static Stretching)
   - แนะนำการดื่มน้ำ เกลือแร่ และการเติมพลังงาน Carbo-loading
