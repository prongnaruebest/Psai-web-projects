# 📖 นิยายเซียนหนี่ 44 เล่มจบ (Xian Ni Cloud E-Reader)

> **โปรเจกต์ลำดับที่ 13** ในศูนย์รวมเว็บแอปพลิเคชัน (Psai Web Projects)  
> ระบบอ่าน E-Book และนิยายกำลังภายในมหากาพย์ 44 เล่มจบสมบูรณ์ (2,088 ตอน) พร้อมระบบอ่านออกเสียงจำลอง (TTS) และเปิดอ่านแบบออฟไลน์

---

## 🌟 ฟีเจอร์หลัก (Key Features)

1. **ฉบับสมบูรณ์ 44 เล่ม 2,088 ตอน:**
   - รวมเนื้อหาครบชุด พร้อมระบบโหลดข้อมูลแบบ Chunking ทีละเล่ม โหลดไวในเสี้ยววินาที
   - มีไฟล์ PDF, EPUB และ ZIP สำหรับดาวน์โหลดเก็บไว้อ่านภายนอก
2. **ระบบอ่านออกเสียงจำลอง (Text-to-Speech & Audiobook):**
   - รองรับ Web Speech API สังเคราะห์เสียงอ่านภาษาไทยต่อเนื่อง
   - ปรับความเร็วเสียง (0.8x - 2.0x) และระดับเสียงสูงต่ำได้
3. **ปรับแต่งประสบการณ์การอ่านระดับพรีเมียม:**
   - ธีมถนอมสายตา 4 สไตล์: สว่าง (Light), ถนอมสายตา (Sepia), มืด (Dark) และป่าลึก (Forest)
   - ปรับขนาดฟอนต์ ระยะห่างระหว่างบรรทัด และขอบกระดาษ
   - จำบทและตำแหน่งการอ่านล่าสุดอัตโนมัติ (Resume Reading)
4. **PWA & Cloud Live:**
   - ใช้งานเวอร์ชันออนไลน์ได้ที่: [https://xianni-reader-psai.netlify.app/](https://xianni-reader-psai.netlify.app/)
   - มีคู่มือสถาปัตยกรรมฉบับสมบูรณ์ใน [`NOVEL_READER_MASTER_GUIDE.md`](NOVEL_READER_MASTER_GUIDE.md)
