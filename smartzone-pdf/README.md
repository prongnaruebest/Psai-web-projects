# 📖 Smart Zone AI (sZai) - PDF Studio & Interactive Flipbook

> **โปรเจกต์ลำดับที่ 17** ในศูนย์รวมเว็บแอปพลิเคชัน: โคลนและพัฒนาต่อยอดจากแนวคิดเว็บไซต์ [szai.net](https://www.szai.net)
> ระบบประมวลผลไฟล์ PDF แบบ Client-Side 100% ภายในเบราว์เซอร์ของคุณ ไร้การส่งข้อมูลขึ้นเซิร์ฟเวอร์ (Zero Uploads) ปลอดภัย รวดเร็ว และทำงานได้แบบออฟไลน์

---

## 🌟 ฟีเจอร์หลัก (Key Features)

### 1. 📖 Interactive 3D Flipbook
- เปลี่ยนไฟล์ PDF ใดๆ ให้กลายเป็นหนังสือเปิดอ่านแบบ 3 มิติ สมจริงด้วยฟิสิกส์การงอหน้า (Page-Curl) และเงาตกกระทบ (Hard & Soft Shadows)
- จำลองเสียงพลิกหน้ากระดาษแบบอะคูสติก (Acoustic Page-Turn Sound) ด้วย Web Audio API สังเคราะห์เสียงแบบเรียลไทม์ไม่ต้องโหลดไฟล์เสียงภายนอก
- รองรับทั้งการเปิดอ่านแบบ 2 หน้าคู่ (Dual-spread) บนจอคอมพิวเตอร์ และหน้าเดี่ยว (Single-page) บนมือถือ
- ระบบควบคุมครบครัน: ถอยหลัง, ถัดไป, ช่องกรอกหมายเลขหน้าเพื่อกระโดดข้าม, ถาดดูภาพตัวอย่างทุกหน้า (Thumbnails Drawer)
- **Standalone HTML Exporter:** สามารถส่งออกเป็นไฟล์ `.html` เดี่ยวๆ นำไปเปิดอ่านได้ทุกอุปกรณ์ ไม่ต้องพึ่งพาเซิร์ฟเวอร์

### 2. ✏️ Edit PDF (Visual Annotation & Redaction)
- **เครื่องมือตกแต่งและแก้ไข:**
  - เพิ่มกล่องข้อความ (Text) ปรับขนาดฟอนต์และสีได้
  - ปากกาวาดเขียน (Freehand Pen)
  - ปากกาไฮไลต์ข้อความโปร่งแสง (Marker Highlighter)
  - เซ็นเซอร์ข้อมูลลับ (Redaction Blackout Block)
  - กล่องสี่เหลี่ยม (Rectangle Shape)
  - ตรายางประทับเอกสารด่วน (Quick Stamps: `CONFIDENTIAL`, `APPROVED`, `DRAFT`)
- **ลายเซ็นดิจิทัล (Digital Signature Pad):** หน้าต่างวาดลายเซ็นด้วยเมาส์หรือปากกาทัชสกรีน พร้อมแทรกลงในเอกสารทันที
- **PDF-Lib Vector Burning:** บันทึกและเบิร์นองค์ประกอบทั้งหมดลงในโครงสร้างเวกเตอร์ของ PDF โดยตรง ทำให้เอกสารที่เซฟมีความคมชัดระดับสูง

### 3. 📑 Merge PDFs (รวมหลายไฟล์เป็นไฟล์เดียว)
- รองรับการเลือกและลากวางหลายไฟล์ PDF พร้อมกัน
- แสดงข้อมูลขนาดไฟล์และจำนวนหน้าของแต่ละไฟล์
- ปุ่มจัดเรียงลำดับไฟล์ (เลื่อนขึ้น/เลื่อนลง) ได้ตามใจชอบ
- รวมเอกสารทั้งหมดเข้าเป็นไฟล์ PDF เดียวอย่างรวดเร็ว

### 4. ✂️ Split PDF (แยกหน้าเอกสาร)
- **แบบที่ 1:** แยกทุกหน้าออกเป็นไฟล์ PDF เดี่ยวหน้าละ 1 ไฟล์ แล้วแพ็กเป็นไฟล์ `.ZIP` ให้ดาวน์โหลดครั้งเดียว
- **แบบที่ 2 (Custom Range):** ระบุช่วงหน้าที่ต้องการดึงออกมา เช่น `1-2, 4` รวมเป็นไฟล์ PDF ใหม่

### 5. 🗂️ Organize Pages (จัดเรียงหน้าเอกสาร)
- แสดงหน้าเอกสารทุกหน้าในรูปแบบ Visual Grid การ์ดพรีวิว
- หมุนหน้าทีละ 90° ตามเข็มนาฬิกา (↻) หรือทวนเข็มนาฬิกา (↺)
- สลับลำดับหน้า เลื่อนซ้าย (◀) หรือเลื่อนขวา (▶)
- ลบหน้าเอกสารที่ไม่ต้องการออก (🗑)
- บันทึกโครงสร้างเอกสารใหม่และดาวน์โหลดทันที

### 6. 🖼️ PDF to Images (แปลง PDF เป็นไฟล์ภาพ)
- แปลงทุกหน้าของ PDF เป็นไฟล์ภาพ `PNG` (คมชัดสูง) หรือ `JPG` (ขนาดกะทัดรัด)
- เลือกความละเอียดได้: 1x (72 DPI), 2x (150 DPI ความละเอียดสูง), 3x (300 DPI คมชัดพิเศษ)
- ดูพรีวิวภาพทุกหน้าในแกลเลอรี พร้อมปุ่มดาวน์โหลดแยกรายภาพ หรือปุ่มดาวน์โหลดทั้งหมดรวมเป็นไฟล์ `.ZIP`

## 🔒 จุดเด่นด้านความปลอดภัยและความเป็นส่วนตัว (Privacy & Security)

- **Zero Server Uploads:** ไฟล์เอกสาร PDF ทั้งหมดจะถูกเปิดและประมวลผลอยู่ภายในหน่วยความจำ (RAM) ของเว็บเบราว์เซอร์ในเครื่องคุณเท่านั้น ไม่มีการส่งไบต์ใดๆ ข้ามอินเทอร์เน็ต
- **100% Offline Capable:** ทุกไลบรารีที่จำเป็นถูกบันทึกไว้ในโฟลเดอร์ `vendor/` ภายในโปรเจกต์เรียบร้อย ไม่ต้องเชื่อมต่ออินเทอร์เน็ตก็สามารถเปิดใช้งานได้สมบูรณ์

## 🛠️ สถาปัตยกรรมและเทคโนโลยีที่ใช้ (Tech Stack)

| ส่วนประกอบ | รายละเอียด |
|---|---|
| **User Interface** | HTML5, Modern CSS3 Cyber Theme (Dark SaaS Palette `#090c10` / `#1fe0ad`), Glassmorphism |
| **PDF Rendering** | `pdf.js` (Mozilla) v3.11 พร้อม Worker สำหรับเรนเดอร์ภาพหน้า PDF แบบคมชัด |
| **PDF Manipulation** | `pdf-lib` v1.17 สำหรับสร้าง, รวม, แยก, หมุนองศา และเบิร์นข้อความ/ลายเซ็นลง PDF |
| **Flipbook Engine** | `StPageFlip` (St.PageFlip) สำหรับคำนวณฟิสิกส์ 3D การพลิกหน้ากระดาษ |
| **Archive Compression** | `JSZip` สำหรับการบีบอัดไฟล์ภาพและไฟล์ PDF แยกหน้าลงใน `.zip` แบบ Client-Side |
| **Audio Engine** | Web Audio API สำหรับสังเคราะห์เสียงพลิกหน้ากระดาษแบบ Dynamic Envelope |

3. หากไม่มีไฟล์ PDF ในเครื่อง ให้คลิกปุ่ม **"📄 โหลดไฟล์ตัวอย่าง Demo"** เพื่อทดลองเล่นทุกฟังก์ชันได้ทันที!
