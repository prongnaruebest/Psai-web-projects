# ⚔️ TITAN FORGE: Anime Bodyweight RPG

> **เว็บออกกำลังกายสไตล์อนิเมะ RPG** (ส่วนหนึ่งของ FastFit Studio Suite)  
> แปลงการออกกำลังกายแบบบอดี้เวทธรรมดาให้เป็นการผจญภัยสุดเร้าใจเพื่อปราบไททัน ปลดปล่อยพลังนักรบในตัวคุณ!

---

## 🌟 ฟีเจอร์หลัก (Key Features)

1. **ระบบเควสต์และค่าสเตตัส RPG:**
   - แปลงจำนวนครั้งการวิดพื้น (Push-up), สควอท (Squat), ดึงข้อ (Pull-up) และแพลงก์ (Plank) ให้เป็นค่าพลังโจมตีและ EXP
   - สะสมเลเวล อัปเกรดคลาสของตัวละคร และปลดล็อกฉายาสุดเท่
2. **โหมดลุยบอสไททัน (Boss Raid):**
   - ท้าทายบอสระดับต่างๆ ที่มีหลอดเลือด HP จริง
   - ยิ่งออกกำลังกายได้ตามเป้า เลือดของบอสจะยิ่งลดลง พร้อมแอนิเมชัน Hit Effect
3. **ระบบเสียงและแอนิเมชันเร้าใจ:**
   - Sound FX ปลุกใจสไตล์อนิเมะต่อสู้
   - ตัวจับเวลานับถอยหลังพักเซ็ต (Rest Timer) พร้อมเสียงเตือน
4. **Offline 100%:**
   - ใช้งานได้ทุกที่โดยไม่ต้องต่อเน็ต และถูกรวมเข้าเป็นโหมดที่ 2 ใน `16_FastFit_Fitness_Studio` ด้วย

---
