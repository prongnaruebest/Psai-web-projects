ROADMAP TO MASTERY

เส้นทางการฝึกวิ่ง: จากคนไม่เคยวิ่ง สู่นักวิ่งมาราธอน

กดเลือกแต่ละระยะเพื่อดูเทคนิคและสั่งให้ตัวละครสาธิตจังหวะการก้าวเท้า! กุญแจสำคัญคือ **ความสม่ำเสมอ** และการรักษา **Zone 2 Heart Rate**

ขั้นที่ 1 (Phase 1) 🌱

Couch to 3K (ปลุกพลัง)

สัปดาห์ที่ 1 - 3: เดินเร็วสลับวิ่งเบาๆ ฝึกการหายใจทางกะบังลม

ตารางซ้อม เดิน 3 นาที + วิ่ง 2 นาที
เป้าหมายหัวใจ Zone 1 - 2 (120-135 bpm)
▶ คลิกเพื่อดูอนิเมชั่นวิ่งคุมโซน
ขั้นที่ 2 (Phase 2) 🏃

5K Finisher (ก้าวไม่หยุด)

สัปดาห์ที่ 4 - 6: พัฒนารอบขา (Cadence 170-180 spm) วิ่งต่อเนื่องไม่เมื่อย

วันพฤหัสบดี Stride สปรินต์ 100m x 4 รอบ
วันอาทิตย์ Long Run 5.0 กม.
▶ คลิกเพื่อดูอนิเมชั่นสปีดรอบขา
ขั้นที่ 3 (Phase 3) 🔥

10K Mini Marathon

สัปดาห์ที่ 7 - 10: Interval 400m และ Tempo Run ขยายปอดและหัวใจ

วันอังคาร Interval 400m x 6 (พัก 90s)
วันอาทิตย์ LSD 10.0 กม. (Zone 2)
▶ คลิกเพื่อดูอนิเมชั่น Interval
ขั้นที่ 4 (Phase 4) 👑

21K - 42.195K Legend

สัปดาห์ที่ 11 - 16+: บริหารไกลโคเจน ดื่มเจล และยืนระยะทางไกล

วันเสาร์ Long Run 21.1 กม. (Half)
การเติมพลัง เจลทุก 45 นาที + จิบน้ำ
▶ คลิกเพื่อดูอนิเมชั่น Long Run

🎧 หัวใจสำคัญของการวิ่งไม่ให้เจ็บเข่า (Form & Cadence)

1. การวางเท้า (Foot Strike)

หลีกเลี่ยงการกระแทกส้นเท้า (Overstriding) ให้ลงกลางเท้า (Mid-foot) ใต้จุดศูนย์ถ่วงของสะโพก เพื่อกระจายแรงกระแทกสู่กล้ามเนื้อแทนข้อต่อ

2. รอบขา & การแกว่งแขน (Cadence)

รักษารอบขา 170-180 ก้าวต่อนาที แขนงอ 90 องศา แกว่งตรงหน้า-หลัง ไม่แกว่งตัดลำตัว ช่วยประหยัดออกซิเจนได้ถึง 15%

3. ทรงตัวและการหายใจ (Posture)

โน้มตัวไปข้างหน้าเล็กน้อยจากข้อเท้า (Ankle lean) ตาและหน้ามองตรง หายใจลึกถึงช่องท้องแบบ 2:2 สัมพันธ์กับก้าวเท้า
