# เมนูของปรายใส รุ่น 2

เว็บภาษาไทยสำหรับค้นหาไอเดียอาหารเด็กจากวัตถุดิบที่มีอยู่ในบ้าน ทำงานแบบ Static Site บน GitHub Pages โดยไม่ใช้ระบบสมาชิกหรือฐานข้อมูลแบบเสียค่าใช้จ่าย

## ความสามารถ

- วัตถุดิบมากกว่า 70 รายการและสูตรอาหารมากกว่า 50 เมนู
- จัดอันดับด้วยวัตถุดิบหลัก วัตถุดิบเสริม และอุปกรณ์ที่มี
- กรองตามวัย มื้ออาหาร เวลา เนื้อสัมผัส และสารก่อภูมิแพ้
- แสดงปริมาณวัตถุดิบ วิธีทำ คำเตือน และการเก็บรักษา
- รายการโปรด ประวัติเมนู เมนูที่ทำแล้ว และรายการซื้อของ
- เก็บการตั้งค่าใน LocalStorage ของอุปกรณ์เท่านั้น

## โครงสร้าง

- `index.html` โครงหน้าและกล่องโต้ตอบ
- `css/styles.css` รูปแบบ Responsive
- `data/ingredients.js` ฐานข้อมูลวัตถุดิบ
- `data/recipes.js` ฐานข้อมูลสูตรอาหาร
- `js/matcher.js` ระบบให้คะแนนและเรียงเมนู
- `js/storage.js` การบันทึกข้อมูลในอุปกรณ์
- `js/validation.js` ตรวจความสัมพันธ์ของข้อมูล
- `js/app.js` การทำงานของส่วนติดต่อผู้ใช้
- `tests/` ชุดทดสอบข้อมูลและระบบจับคู่

## เพิ่มวัตถุดิบหรือสูตร

เพิ่มวัตถุดิบใน `data/ingredients.js` โดยใช้ `id` ที่ไม่ซ้ำ จากนั้นอ้างอิง `id` เดียวกันใน `requiredIngredients` หรือ `optionalIngredients` ของสูตรใน `data/recipes.js` แล้วรัน `npm test`

## ทดสอบ

```bash
npm test
python3 -m http.server 8000
```

เปิด `http://localhost:8000` ไม่ควรเปิด `index.html` ผ่าน `file://` เพราะเว็บใช้ JavaScript modules

## ข้อจำกัดด้านข้อมูล

สูตรเป็นแนวทางทั่วไปและยังไม่ได้รับการตรวจรายสูตรโดยกุมารแพทย์หรือนักกำหนดอาหาร จึงไม่แสดงการคำนวณพลังงานหรือสารอาหารเชิงปริมาณ และไม่ใช้แทนคำแนะนำทางการแพทย์

## การเผยแพร่

GitHub Pages ใช้สาขา `main` และโฟลเดอร์ `/(root)` ทุกพาธในเว็บเป็น Relative path เพื่อรองรับ URL ของ Repository
