# 💰 เงินเดือนนี้ต้องรอด (Money Survival Hub)

> **โปรเจกต์ลำดับที่ 18** ในศูนย์รวมเว็บแอปพลิเคชัน (Psai Web Projects)  
> ระบบบันทึกและวางแผนรายรับ-รายจ่ายรายเดือน จัดสรร 3 ซอง คุมงบกินอยู่ 10,000 บ. ตัดหนี้ ค่านมลูก พร้อมคำแนะนำจากนักวางแผนการเงิน CFP

---

## 🌟 ฟีเจอร์หลัก (Key Features)

1. **ระบบจัดสรรงบประมาณ 3 ซอง:**
   - **ซองที่ 1:** ค่าใช้จ่ายคงที่ & ภาระหนี้สิน (ค่าเช่า/บ้าน, ค่างวด, หนี้บัตร)
   - **ซองที่ 2:** คุมงบกินอยู่รายวัน (ตั้งเป้า 10,000 บาท/เดือน พร้อมคำนวณเงินเฉลี่ยต่อวัน)
   - **ซองที่ 3:** กองทุนครอบครัวและเงินเก็บเพื่ออนาคตลูก (ค่านม, แพมเพิส, เงินออมฉุกเฉิน)
2. **Interactive Financial Dashboard:**
   - กราฟวงกลมแสดงสัดส่วนรายจ่ายด้วย Chart.js
   - แถบวัดสุขภาพทางการเงิน (Financial Health Gauge)
   - สรุปกระแสเงินสดสุทธิ (Net Cash Flow) แบบเรียลไทม์
3. **คำแนะนำจากผู้เชี่ยวชาญ (CFP Advisor AI Insights):**
   - วิเคราะห์จุดเสี่ยงของงบประมาณและให้คำแนะนำลดรายจ่ายที่ไม่จำเป็น
   - แผนปลดหนี้แบบ Snowball / Avalanche
4. **ความปลอดภัยและความเป็นส่วนตัว 100%:**
   - บันทึกข้อมูลทั้งหมดลงใน LocalStorage ของเบราว์เซอร์ ไม่มีการส่งข้อมูลการเงินขึ้นเซิร์ฟเวอร์
   - สามารถส่งออก (Export) และนำเข้า (Import) ข้อมูลสำรองเป็นไฟล์ JSON ได้
